## 关于智读

智读希望把电子书阅读做成一段更有温度的独处时间。你可以导入自己的电子书，在舒适的排版和阅读模式中继续阅读；也可以在读到某个段落时，和“伴知己”聊聊感受，或请“解先生”帮助理解一段文字。

AI 只在你主动调用并配置 API 后工作。书籍、笔记和阅读进度默认保存在本机。

## 下载与安装

打开 Releases 页面，下载最新版本中的 APK 安装包，在 Android 手机上允许本次安装来源后完成安装。当前发布页只提供 Android 安装包，不包含源代码。

## AI 与隐私

智读不内置 AI 服务，也不代替用户提供 API Key。可配置兼容 OpenAI 格式的 DeepSeek、通义千问、OpenAI 或本地 Ollama。除用户主动发起的 AI 请求外，应用不会主动上传本地书籍和笔记内容。

## 书城说明

书城只提供经过审核的公版书资源导航，不托管、不修改、不传播第三方书籍内容。当前收录文硕阁：https://www.wenshuoge.com/。内置浏览器只允许访问代码中预设的白名单域名。
