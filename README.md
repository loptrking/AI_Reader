## 关于智读

智读希望把电子书阅读做成一段更有温度的独处时间。你可以导入自己的电子书，在舒适的排版和阅读模式中继续阅读；也可以在读到某个段落时，和“伴知己”聊聊感受，或请“解先生”帮助理解一段文字。

书籍、笔记和阅读进度默认保存在本机。AI 仅在用户主动配置服务并发起请求时工作。

## 公测版 0.5.0925

2026 年 9 月 25 日更新。

本次更新继续完善 AI 交互、笔记写作与系统稳定性：

### 新增与优化

- 新增智谱 GLM 服务商支持，API 设置可按厂商快速选择模型，并支持为各厂商保存自定义模型名称
- 新增完整的应用内使用手册，支持目录跳转、关联词跳转、返回上一阅读位置和常见错误自助排查
- 伴知己五种陪读模式加入默认回答深度：标准为轻度，角色扮演与吐槽为简短，思想家与感性者为标准；切换后仍可手动调整
- Token 用量统计仅保留最近 30 天，并继续按日期和解先生、伴知己、笔记 AI 分类展示
- 优化强检索 Agent 的多轮调用与语义检索流程，可在同一会话中反复启用，并更好地理解隐含表达和复杂问题
- 优化笔记 AI 的上下文读取，续写与讨论会结合光标前后内容，支持在文章中间自然续写、润色、扩写和精简

### 问题修复

- 修复复制或粘贴正文后，笔记 AI 偶尔仍提示“请先输入文字”的问题
- 修复系统夜间模式影响部分浅色界面文字，导致封面、续写结果等内容对比度不足的问题
- 修复离开设置次级菜单后，再次进入设置仍停留在旧页面的问题
- 修复笔记 AI 浮窗打开时，安卓返回手势可能直接退出笔记编辑器的问题
- 修复部分模型只返回思考过程而没有正文时，错误提示缺少明确排查入口的问题
- 优化首次进入 API 设置等页面时的加载反馈，并禁止加载期间重复触发

## 使用说明

### 开始阅读

1. 在书库点击导入按钮，从手机中选择 TXT、EPUB、PDF、MOBI 或 AZW3 文件。
2. 点击书籍封面进入阅读。应用会自动保存阅读位置，下次打开可继续阅读。
3. 点击阅读页面可显示或隐藏上下菜单；在设置中可切换上下滚动或左右翻页。
4. 阅读到章节末尾后，可继续滑动进入下一章，也可使用章节切换按钮。

### 使用 AI

1. 进入“设置 → API 设置”，填写兼容 OpenAI 格式的服务地址、模型和 API Key。
2. 使用“测试连接”确认配置可用。
3. 阅读时选中文字或打开 AI 功能，选择伴知己交流感受，或请解先生解释文本。
4. 伴知己支持多会话、五种内置陪读模式、四档回答深度和按需全书检索。
5. 启用自定义伴知己系统提示词后，五种内置模式会暂时禁用；清空自定义提示词即可恢复。
6. API 请求会发送至你选择的 AI 服务商，请勿在对话中发送敏感信息。

### 使用笔记

- 在笔记栏目点击新建笔记，可创建、编辑、搜索、置顶或删除自定义笔记。
- 长按笔记并左滑，可显示置顶或取消置顶、删除按钮；右滑可收回操作按钮。
- 笔记 AI 通过悬浮按钮打开，可选择续写或讨论；讨论不会修改正文。
- 编辑笔记时支持自动保存、撤销与重做、版本历史，以及对选中文字进行 AI 润色、扩写和精简。
- 伴知己聊天记录可以导出到笔记，记录可打开、删除和复制，但不可编辑或导出。
- 自定义笔记可以导出为 TXT 或 EPUB，也可以加入本地书库；不支持从外部文件导入笔记。

### 使用书城

书城仅提供经过审核的公版书资源导航。首次进入需阅读并同意声明；内置浏览器只允许访问白名单域名。当前收录文硕阁，下载的支持格式会导入应用私有书库，不写入公共 Download 文件夹。

## 下载与安装

打开 [Releases](../../releases) 页面，下载最新公测版 APK。在 Android 手机上允许本次安装来源后完成安装。

本仓库只提供 Android 安装包、使用说明和界面截图，不包含源代码。公测版可能存在兼容性问题，建议保留原始电子书文件和重要笔记备份。

## AI 服务与隐私

智读不内置 AI 服务，也不代替用户提供 API Key。你可以配置兼容 OpenAI 格式的 DeepSeek、通义千问、OpenAI 或本地 Ollama。除用户主动发起的 AI 请求外，应用不会主动上传本地书籍和笔记内容。启用全书检索时，应用会按需向所配置的 AI 服务发送检索到的相关书籍片段。第三方服务的数据处理以其隐私政策为准。

## 测试反馈

如果你遇到崩溃、排版异常、章节识别错误或 AI 回复问题，欢迎提交 [Issue](../../issues)。建议附上手机型号、Android 版本、电子书格式和复现步骤。请不要公开 API Key、个人信息或受版权保护的完整书籍内容。
